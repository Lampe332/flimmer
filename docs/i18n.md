# UI language (i18n)

Addition to `docs/API.md`, to be merged there.

## `?lang=` on every `/api` call

Every `/api/...` request may carry `lang=<xx>` or `lang=<xx-YY>` (ISO 639-1, optional ISO 3166-1 region), for
example `lang=en-US`, `lang=ja-JP`, `lang=pt-BR`. The server passes it to TMDB as `language`, so these fields come
back in that language:

- titles and overviews (`Item.title`, `Item.overview`, `Details.tagline`, recommendations, search results)
- seasons and episodes (`Season.name`, `Episode.name`, `Episode.overview`)
- genres (`/api/genres/{type}`, `Details.genres`)
- the TMDB part of `/api/continue` and `/api/new-episodes` (episode names, air dates)

Without `lang`, `config.language` applies, exactly as before. An invalid value (`lang=english`, `lang=en_us`)
answers `400 { "error": "'lang' must look like 'de-DE' or 'en-US'" }`.

Trailers (`Details.trailer_youtube_key`): the request language first, then English, then German, then any
language. `include_video_language` is sent as `<lang>,<en or de>`.

The TMDB cache is keyed by the full query including `language`, so every language has its own cache entries.
Data Flimmer stores itself (watchlist items, history and progress entries) keeps the text from the moment it was
saved; it is not translated afterwards.

## The web UI

- Languages: `de` (default), `en`, `fr`, `es`, `it`, `pt` (pt-BR), `ru`, `pl`, `tr`, `ja`, `zh` (zh-CN), `ko`.
- Choice: header button with the current code (e.g. `DE`), opens Settings with the language list. Stored in
  `localStorage["flimmer.lang"]`. First start: the first system language Flimmer speaks, else German.
- The UI sends `lang=<locale>` with every API call (`de-DE`, `en-US`, `fr-FR`, `es-ES`, `it-IT`, `pt-BR`, `ru-RU`,
  `pl-PL`, `tr-TR`, `ja-JP`, `zh-CN`, `ko-KR`) and refetches TMDB-backed queries after a switch.
- Code: `web/src/i18n/index.ts` (store, `useI18n()`, `t()`, plurals via `Intl.PluralRules`),
  one dictionary per language in `web/src/i18n/<id>.ts`, each typed `Dict` (the keys of `de.ts`), so a missing or
  extra key fails `npm run build`.
